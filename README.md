# NKScanpdf

Ứng dụng web (PWA) scan tài liệu trên điện thoại: chụp, tự nhận mép giấy, nắn phẳng, làm nét, chụp CCCD 2 mặt trên 1 trang A4 và xuất PDF. Chạy offline, ảnh chỉ xử lý trên máy.

**Cài lên điện thoại:** mở trang GitHub Pages của repo này
- Android (Chrome): bấm **Cài app**.
- iPhone (Safari): nút Chia sẻ → **Thêm vào MH chính**.

**Cập nhật phiên bản mới:** tải đè các tệp lên repo, rồi tăng số `CACHE` trong `sw.js` để điện thoại nhận bản mới.
